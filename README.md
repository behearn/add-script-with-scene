# Add Script With Scene

Godot 4 editor plugin. The Create New Scene dialog gets an Add GDScript checkbox, on by default. Confirming the dialog writes a matching `.gd` beside the scene, with `class_name` from the scene name and `extends` from the chosen root type, then attaches it to the root.

## Install

Copy `addons/add_script_with_scene` into your project's `addons` folder. Enable **Add Script With Scene** under Project > Project Settings > Plugins.
